# Kitobcha PDF
Foxit Reader'dagi Booklet rejimiga o'xshash Android ilova.
- PDF tanlash, Binding (chap/o'ng), Subset (ikkala/old/orqa), Margins, Reverse, Letter/A4
- Booklet PDF ni saqlash yoki to'g'ridan-to'g'ri chop etish (Android Print Service)
- Sahifalar soni 4 ga bo'linmasa, oxiriga bo'sh sahifa qo'shiladi

## APK olish
1. GitHub'da yangi repository oching, shu papkadagi hamma fayllarni yuklang (.github papkasi bilan).
2. Actions → "Build APK" tugagach, Artifacts ichidan "Kitobcha-PDF-APK" ni yuklab oling.
